Sign in a terminal

A terminal running cloop login shows a code. Enter it to sign that terminal in to this hub as you.

Ten letters, like BCDFG-HJKLM. Codes expire after ten minutes.

The sign-in request

Only approve a code you started yourself. Approving signs whoever is running that terminal in to this hub as you — your projects, tasks, runs, logs and sandbox terminals, with your permissions — until the session expires or is revoked. If somebody sent you this code or this link, deny it.
